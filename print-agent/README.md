# BRIN Print Agent

خدمة Node.js تطبع تلقائياً على طابعتي المطبخ والعميل الحراريتين (USB أو شبكة) بمجرد ما يوصلها طلب من الكاشير أو المنيو الإلكتروني — لكل جهاز كاشير (STATION_ID) طابعتاه الخاصتان، تدعم أكثر من جهاز كاشير بنفس الوقت.

**ملاحظة مهمة لو جهاز الكاشير آيباد أو تابلت:** آيباد ما يقدر يشغّل خدمة Node.js محلياً (لا يدعم systemd ولا الوصول المباشر لمنفذ USB لطابعة عادية). الحل: هذي الخدمة تشتغل على جهاز مرافق صغير دائم التشغيل بنفس موقع الكاشير فعلياً (Raspberry Pi أو Mini PC رخيص)، موصول بالطابعتين — إما شبكياً (`tcp://...`، الأسهل، الطابعة والجهاز المرافق على نفس شبكة الواي فاي) أو عبر USB مباشرة بالجهاز المرافق نفسه. الآيباد بس يشغّل تطبيق الكاشير بالمتصفح ويُدخل نفس STATION_ID بصفحة "إعدادات الطباعة" — راجع التفاصيل بالأسفل.

## المتطلبات

- Node.js 22+
- pnpm (نفس المستودع الأساسي)
- طابعتان حراريتان متوافقتان مع ESC/POS (Epson أو مثيلاتها)

## الإعداد

1. انسخ `.env.example` إلى `.env` واملأ `NEXT_PUBLIC_SUPABASE_URL` و`SUPABASE_SERVICE_ROLE_KEY` (نفس القيم المستخدمة بباقي التطبيقات).
2. اختر `STATION_ID` فريد لهذا التثبيت (مثال: `cashier-1`) واملأه بـ `.env` — هذا المعرّف لازم يطابق بالضبط اللي يُدخله الكاشير بصفحة "إعدادات الطباعة" بنظام الكاشير على نفس جهازه (تطبيق الكاشير، مو هذا التثبيت بالضرورة — راجع الملاحظة أعلاه لو الكاشير آيباد).
3. عناوين الطابعتين **لا تُضبط هنا** — تُضبط من نظام الكاشير (صفحة "إعدادات الطباعة"، أيقونة 🖨️ بأعلى الصفحة)، ويقرأها هذا التطبيق تلقائياً كل 15 ثانية حسب STATION_ID. متغيرات `KITCHEN_PRINTER_INTERFACE`/`CUSTOMER_PRINTER_INTERFACE` بملف `.env` احتياطية فقط (تُستخدم قبل أول ضبط من نظام الكاشير).

## التشغيل للتجربة

```bash
pnpm install
pnpm --filter @brin/print-agent dev
```

## التشغيل الدائم (خدمة تلقائية عند إعادة التشغيل)

1. انسخ المستودع لموقعه النهائي على الجهاز اللي بيشغّل الخدمة فعلياً — جهاز الكاشير نفسه لو PC/Linux، أو الجهاز المرافق (Raspberry Pi مثلاً) لو الكاشير آيباد/تابلت (مثال: `/opt/brin-system`).
2. أنشئ مستخدم مخصص عضو بمجموعة `lp` (للوصول لمنفذ الطابعة USB):
   ```bash
   sudo useradd --system --group lp --home-dir /opt/brin-system/print-agent brin-print-agent
   ```
3. حدّد المسار الفعلي لـ `pnpm`:
   ```bash
   which pnpm
   ```
   وعدّل `ExecStart` بملف `brin-print-agent.service` ليطابقه، وكذلك `WorkingDirectory` ليطابق مكان المستودع الفعلي.
4. انسخ ملف الخدمة وفعّله:
   ```bash
   sudo cp brin-print-agent.service /etc/systemd/system/
   sudo systemctl daemon-reload
   sudo systemctl enable --now brin-print-agent
   ```
5. للتحقق من الحالة والسجلات:
   ```bash
   sudo systemctl status brin-print-agent
   sudo journalctl -u brin-print-agent -f
   ```

بهذا الإعداد، الخدمة تشتغل تلقائياً عند إقلاع الجهاز، وتعيد التشغيل تلقائياً لو تعطّلت (`Restart=always`).
